# 予備解析：BBJ 公開サマリー統計による候補遺伝子の検討

実施日: 2026-11-18 / スクリプト: `scripts/pilot/pilot_bbj_pheweb.py` / データ: [BBJ PheWeb](https://pheweb.jp)（主に Sakaue & Kanai 2021, GRCh37）
**個票データは使っていない。** 公開 GWAS の要約値だけを使った、申請前の当たり付けである。

## A. 事前に指定した候補 SNP（15 SNP × 5 疾患 = 75 検定、Bonferroni 閾値 P < 6.7×10⁻⁴）

結果の全体: `A_candidate_snps.tsv`（OR, 95%CI, P, 検出可能な最小 OR）/ 各 SNP が最も強く関連する形質: `A_candidate_snps_top_phenotypes.tsv`

### Bonferroni 補正後も有意（すべて ALDH2 rs671、効果アレル A = ALDH2*2、アレル頻度 0.25）

| 疾患 | OR (95%CI) | P |
|---|---|---|
| 脳梗塞 | 0.90 (0.87–0.92) | 2×10⁻¹⁸ |
| 脳出血 | 0.80 (0.73–0.87) | 2×10⁻⁷ |
| てんかん | 0.85 (0.80–0.91) | 5.9×10⁻⁶ |
| 脳動脈瘤 / クモ膜下出血 | 0.93 / 0.91 | 0.024 / 0.046（名目上の有意） |

- 方向は China Kadoorie Biobank の MR（Millwood 2019：飲酒を減らす遺伝型は脳卒中、特に脳出血を減らす）と一致する。**飲酒を介した効果**と考えるのが自然である。
- **てんかんとの関連（OR 0.85）は、検索した範囲では報告が少なく、新規知見の候補。** アルコール関連の発作や、飲酒による脳卒中後てんかんを介する可能性がある。個票データで飲酒歴による層別解析と MR を行い、確認する必要がある。
- 陽性対照：rs671 は γ-GTP（P≈0）、HDL-C（P=4×10⁻¹⁰⁹）、心筋梗塞（OR 1.39）と強く関連した。データは正しく取得できている。
- 注意：12q24（ALDH2–ACAD10–BRAP–SH2B3）は長い距離にわたって LD がある。条件付き解析で rs671 そのものの効果かを確認する。

### 名目上の有意（P < 0.05。多重検定の補正後は有意でない）
- **ADH1B rs1229984**（効果アレル C = Arg48 = ADH1B*1、低活性型）：クモ膜下出血 OR 1.14 (P=0.0099)、てんかん OR 1.07 (P=0.054)
- **TAS2R38**（3 SNP の方向は一致。PAV = taster 型）：**パーキンソン病で PAV アレルの OR ≈ 0.83 (P≈0.016)**。PD では nontaster 型が多いという報告（Cossu 2018）と同じ方向。ただし症例は 340 例で、探索的な結果である。
- **TAS2R38 PAV × 飲酒歴（ever/never）：P ≈ 2×10⁻⁵**。PAV（苦味を感じやすい型）の人は飲酒経験者がやや少ない。→ **当グループのワイン嗜好研究と直接つながる知見。**
- TAS1R2 rs35874116 × てんかん（P=0.043）、OR6A2 rs72921001 × てんかん（OR 0.91, P=0.0041）

### 有意差なし
TAS2R38 と脳血管疾患・てんかんの関連は、いずれも OR ≈ 1.00 で、95%CI は ±5〜10% に収まった。**効果があるとしてもごく小さい**（脳梗塞では OR 1.05 未満）。

## B. 候補遺伝子領域のスキャン（460 遺伝子 → 101 領域、遺伝子の前後 ±50 kb）

結果の全体: `B_region_scan.tsv`、領域の定義: `B_regions.tsv`
方法：アレル頻度 ≥ 0.005、インピュテーション r² ≥ 0.7 のバリアントについて、領域内の最小 P 値 × バリアント数（Bonferroni）で領域 P 値を出し、対象 5 疾患 × 領域で BH-FDR をかけた。

**FDR < 0.05 になったのは 3 つ:**

| 領域 | 疾患 | リードバリアント | P | 解釈 |
|---|---|---|---|---|
| ALDH2 | 脳梗塞 | rs671 | 2×10⁻¹⁸ | A と同じ |
| ALDH2 | 脳出血 | rs671 | 2×10⁻⁷ | A と同じ |
| OR8U8..OR8U9 (11p15.5) | 脳動脈瘤 | rs73392700（**SIRT3** の近傍）, OR 1.32 | 4×10⁻¹² | **OR 遺伝子ではなく、既知の動脈瘤座位 SIRT3**（Hale 2022）を拾ったもの |

- OR / TAS2R / TAS1R の領域では、**対象 5 疾患で FDR < 0.05 のシグナルはなかった。**
- 飲酒歴（陽性対照）：ALDH2, ADH クラスター, ALDH1B1, ALDH1A1 を検出した。加えて **TAS2R38–MGAM 領域（7q34）**でも検出された（FDR 0.009、リードは MGAM/CLEC5A の近傍）。MGAM は Su 2026 が AD のリポジショニング標的として挙げた遺伝子である。
- **OR 遺伝子の 8 領域（OR4F ファミリーなどサブテロメア領域、OR11H1、OR9G9 など）は、フィルターを通るバリアントが 0 で評価できなかった。** OR 遺伝子はアレイとインピュテーションでカバーしきれないことを、実データで確認できた → WGS が必要。
- 注意：±50 kb の窓は、隣の非候補遺伝子の座位（SIRT3 など）を拾う。本解析では eQTL や colocalization で原因遺伝子を確認すること。

## C. 検出力（80%、α = 6.7×10⁻⁴、対照 15 万人）

| 症例数 | MAF 0.05 | MAF 0.25 | MAF 0.42 |
|---|---|---|---|
| ALS 782 例 | OR 1.64 | 1.28 | 1.24 |
| 認知症 1,000 例（仮定） | 1.55 | 1.25 | 1.21 |
| 認知症 3,000 例（仮定） | 1.29 | 1.14 | 1.12 |
| 脳出血 1,456 例 | 1.44 | 1.20 | 1.17 |
| 脳梗塞 22,664 例 | 1.10 | 1.05 | 1.04 |

→ ALS や認知症が 1,000 例前後だと、検出できるのは OR が約 1.2 以上の比較的大きな効果に限られる。ALDH2 × 脳出血（OR 0.80）程度の効果なら検出できる。TAS2R38 のような小さい効果（OR ≈ 1.05 未満）は検出できない。

## 本解析（個票データ）への示唆

1. **主仮説の優先順位:**
   - ALDH2 rs671 × 脳梗塞・脳出血・**てんかん**：確度が高い。てんかんは新規性あり
   - TAS2R38 × 飲酒行動、PD・認知症：探索的だが、嗜好研究と疾患をつなぐ
2. **ALS と認知症は公開データがない** → 本研究の最大の付加価値。症例数を早めに照会する。
3. OR 遺伝子は WGS と遺伝子単位の検定が前提。サブテロメア・セントロメア近傍は解析できない可能性がある。
4. 飲酒歴の扱い（媒介因子）と 12q24 の LD に注意（`docs/study_plan_review.md` B 項）。

## 限界
- PheWeb の値は BBJ の解析パイプラインに依存する（共変量や対照の定義が本計画と異なる）。
- 飲酒形質は線形モデルの beta とみられ、表の OR 列（exp(beta)）は方向だけを示す。男女別の飲酒形質の値が全体と同一で、API 側の問題の可能性がある。
- rs671・rs1229984 などは飲酒 GWAS の variant API に収載がなく、飲酒形質の陽性対照は領域 API の結果を使った。
- 領域 P 値は単純な Bonferroni で保守的。LD を考慮した有効検定数（Meff）は使っていない。
